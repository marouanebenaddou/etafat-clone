Étafat · Communication interne

Un seul modèle de signature, appliqué à tous les comptes

La signature est construite une fois, à partir de l'annuaire Google Workspace d'Étafat (etafat.ma est hébergé chez Google). Une commande la pousse dans le Gmail de chaque collaborateur. Pour changer le design ou ajouter une campagne, on modifie le modèle et on relance la commande.

Tendances retenues pour Étafat

Court et lisible

Trois à cinq lignes, une hiérarchie nette : nom, poste, moyen de contact.

Appliqué : nom, poste · service, deux numéros, un lien.

Pensé mobile

Plus de la moitié des emails pro sont lus sur téléphone.

Appliqué : largeur max 480 px, numéros cliquables, modèle « Compact » pour les réponses.

Compatible mode sombre

Le texte noir disparaît sur fond sombre dans Apple Mail et Outlook.

Appliqué : le modèle Topo nuit porte son propre fond sombre ; les autres utilisent des couleurs lisibles sur les deux fonds.

Un seul appel à l'action

Un lien utile (références, prise de rendez-vous, actualité) au lieu d'une rangée d'icônes.

Appliqué : champ « lien du moment », changé pour toute l'entreprise en une commande.

Peu de réseaux sociaux

Un ou deux liens suffisent, en texte plutôt qu'en icônes hébergées.

Appliqué : LinkedIn et YouTube en liens texte, jamais bloqués par les clients mail.

Gestion centralisée

La signature vient de l'annuaire, plus de copier-coller manuel par chacun.

Appliqué : annuaire Google + GAM, détaillé plus bas.

À éviter : citations, GIF animés (mal affichés par Outlook), image unique contenant tout le texte (illisible si les images sont bloquées), mentions légales de dix lignes.

Mise en place en trois jours

  1. Jour 1 · Communication

    Valider le modèle

    Choisir Topo, Topo nuit, Rail ou Compact dans l'atelier, faire valider par la direction, puis cliquer « Copier le modèle GAM » et enregistrer le contenu dans signature_etafat.html.

  2. Jour 1–2 · RH / IT

    Compléter l'annuaire Google

    Console d'administration → Annuaire → Utilisateurs → chaque fiche : Poste, Service, téléphone mobile. Si l'annuaire est incomplet, un fichier equipe.csv (email, nom, poste, service, mobile) fait l'affaire.

  3. Jour 2 · IT

    Installer GAM sur un poste administrateur

    Installer GAM7 depuis github.com/GAM-team/GAM, puis lancer gam config et autoriser le projet avec un compte super-administrateur (assistant guidé, environ 30 minutes).

  4. Jour 2 · IT

    Tester sur deux comptes pilotes

    Pousser la signature sur deux personnes et vérifier : Gmail web, Gmail iPhone et Android, Outlook chez un client, mode sombre, images bloquées.

    # un seul compte
gam user m.benaddou@etafat.ma signature file signature_etafat.html html \
  replace Nom field:name.fullname replace Poste field:organization.title \
  replace Service field:organization.department replace Mobile field:phone.value.type.mobile \
  replace Email field:primaryemail
  5. Jour 3 · IT

    Déployer à toute l'entreprise

    Même commande avec all users à la place de user …. Variante avec le fichier CSV si l'annuaire n'est pas rempli :

    gam all users signature file signature_etafat.html html replace Nom field:name.fullname ...

# variante CSV (colonnes : email,nom,poste,service,mobile)
gam csv equipe.csv gam user ~email signature file signature_etafat.html html \
  replace Nom ~nom replace Poste ~poste replace Service ~service \
  replace Mobile ~mobile replace Email ~email
  6. Ensuite · en continu

    Mettre à jour en 2 minutes

    Nouveau lien, salon, changement de logo : modifier signature_etafat.html et relancer la commande « all users ». Nouvelle recrue : créer sa fiche dans l'annuaire, puis lancer la commande sur son seul compte. Les blocs entourés de {RT}…{/RT} disparaissent quand le champ est vide (par exemple pas de mobile).

Règles du modèle

À respecter pour toute nouvelle version

  • Mise en page en tableaux HTML avec styles en ligne : c'est ce que lisent Gmail et Outlook.
  • Images hébergées en ligne (adresse https absolue : logo sur etafat.ma, courbes sur etafat-new.vercel.app), jamais en pièce jointe.
  • Texte alternatif sur le logo, pour les clients qui bloquent les images.
  • Police Open Sans avec repli Arial : la plupart des clients mail n'affichent pas les polices web.
  • Largeur inférieure à 480 px, taille de texte minimale 12 px.
  • Signature HTML de moins de 10 000 caractères : c'est la limite de Gmail.
